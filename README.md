# 안면 밸런스 코치 (QA 빌드)

카메라로 얼굴 좌우 균형과 평소 고개 자세를 측정하고, 결과에 맞춘 교정 운동을 안내하는 macOS 앱입니다.
모든 사진과 기록은 이 컴퓨터에만 저장되며 외부로 전송되지 않습니다.

## 다운로드

👉 **[최신 버전 다운로드 (Releases)](../../releases/latest)** — `안면밸런스코치-QA-x.x.x.dmg` 파일을 받으세요.

## 설치

1. 받은 DMG 파일을 더블클릭해 엽니다.
2. `안면 밸런스 코치` 앱을 옆의 `Applications`(응용 프로그램) 폴더로 끌어다 놓습니다.

## 처음 실행할 때

개발자 인증을 받지 않은 테스트용 앱이라 macOS가 처음 실행을 막습니다.

1. 응용 프로그램 폴더에서 앱을 **우클릭 → 열기**를 누르고, 경고 창에서 다시 **열기**를 누릅니다.
   - 열기 버튼이 없다면: **시스템 설정 → 개인정보 보호 및 보안**에서 아래쪽의 **그래도 열기**를 누릅니다.
2. 카메라 권한을 묻는 창이 뜨면 **허용**합니다.

## 지원 환경

- Apple Silicon(M1 이상) Mac, macOS 11 이상
- Intel Mac은 지원하지 않습니다.

## 사용 순서

1. **정면 촬영** — 노트북 정면에 편하게 앉아(화면에서 약 50~70cm) 화면 가운데를 보며 고개를 살짝 좌우로 흔듭니다.
2. **미소 · 턱 열고 닫기 · 고개 돌리기** — 안내에 따라 진행합니다(건너뛰기 가능).
3. **습관 고르기** — 해당하는 자세·습관을 선택합니다(건너뛰기 가능).
4. **결과 확인** — 대칭 점수, 세부 측정값, 고개 정렬, 연관 증상, 맞춤 교정 운동을 확인합니다.
5. **교정 운동** — 얼굴 위 색칠 부위와 화살표를 따라 운동합니다. 매일 하면 출석이 쌓입니다.

## 주의

이 앱은 자가 점검·생활 관리용이며 의학적 진단이 아닙니다.
턱 통증, 입 벌리기 어려움, 팔 저림, 갑작스러운 비대칭 변화가 있다면 치과(구강내과)·정형외과 진료를 받으세요.
